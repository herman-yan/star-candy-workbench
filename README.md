# 🍬 爱心小软糖成长世界 · 个人学习激励工作台

专为 6 岁半一年级小学生设计的轻量化、游戏化学习激励工作台。家长远程发布任务、孩子自主打卡、晶石自动结算、奖励兑换审批、数据可视化统计，形成完整闭环。

## ✨ 功能模块

- **📋 任务台**：预设 + 自定义任务（阅读 / 数学 / 英语 / 运动 / 练字 / 语文 / 生活等，含跳绳 100 个 = 1💎 等梯度），孩子打卡即时获得爱心晶石 💎
- **🗣️ 口语**：贝答英语式口语练习——听示范 → 🎤 跟读 → 录音识别 → 星级评分反馈（目标句 vs 我读对比），无麦克风也能打字打卡
- **🛒 补给站**：奖励商店（休闲福利 / 学习物资 / 实物）+ 心愿许愿，所有兑换需家长审批通过才扣石
- **📡 雷达**：连续 / 累计打卡天数、今日完成率、断卡记录、晶石收支资产、完整流水、审批日志四类统计可视化
- **💬 微信**：家长 ↔ 孩子消息联动（自动流转通知）+ 微信同步串（跨设备数据通道，绕开 localStorage 单设备限制）

## 🚀 使用方式

直接用浏览器（或 iPad Safari / Chrome）打开 `super-power-workbench.html` 即可使用，无需安装、无需联网。

- 数据备份：⚙️ 数据管理 → 📤 导出 / 📥 导入 JSON
- 跨设备同步：⚙️ 微信同步串 → 生成同步串发给对方，对方粘贴即同步

## 🛠 技术说明

纯原生 HTML / CSS / JS 单文件，零依赖、零后端。晶石以 `ledger` 流水为唯一账本，余额 / 累计收支全部派生，保证数据一致。所有学习、积分、兑换数据仅存于本地浏览器，不联网、不上云。

## 📡 部署（GitHub Pages）

本仓库可一键开启 GitHub Pages：仓库 **Settings → Pages → Source** 选 `main` 分支、`/ (root)` 目录，保存后通过以下地址访问：

```
https://<用户名>.github.io/<仓库名>/
```

## 🔐 隐私

所有数据本地存储，不上传任何云端服务器。
